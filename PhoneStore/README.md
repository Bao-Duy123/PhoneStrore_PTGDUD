# PhoneStore - Next.js

Cửa hàng điện thoại với tính năng đăng nhập/đăng ký.

## Tính năng

- Hiển thị sản phẩm điện thoại
- Đăng nhập / Đăng ký tài khoản
- Bảo vệ route với middleware
- Redux cho quản lý state authentication

## Tài khoản demo

| Role  | Số điện thoại  | Mật khẩu    |
|-------|-----------------|-------------|
| Admin | 0909123456     | admin123    |
| User  | 0909123457     | password123 |

## Cài đặt

```bash
npm install
npm run dev
```

## Tech Stack

- Next.js 14
- TypeScript
- Redux Toolkit
- Tailwind CSS
- bcryptjs (password hashing)
- jsonwebtoken (JWT authentication)
